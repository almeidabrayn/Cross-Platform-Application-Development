# Cross-Platform Application Development 📱💻

Repositório dedicado ao armazenamento e organização dos códigos, projetos e atividades desenvolvidos durante as aulas de Desenvolvimento de Aplicações Cross-Platform (Multiplataforma) desenvolvidos na aulas da FIAP

## 📂 Estrutura do Repositório

O projeto está organizado por pastas representando cada aula prática:

* **Aula 3/** - Componentes, Props e Flatlists
* **Aula 4/** - Flexbox
* **Aula 5/** - Navegação entre Telas
* **Aula 6/** - Tab Navigator

## 🛠️ Tecnologias Utilizadas

* **JavaScript / TypeScript**
* **React Native / Expo** (ou o framework cross-platform que você está utilizando em aula)
